# 예사랑피아노학원 홈페이지

첨부된 기존 디자인을 유지한 반응형 정적 홈페이지입니다. 별도 패키지 설치나 빌드가 필요하지 않습니다.

## 로컬 실행

```sh
cd /workspace/gazua
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 열어 자동·봄·여름·가을·겨울 버튼을 확인하세요. 선택한 테마는 같은 브라우저에 저장되며 자동 모드는 기기의 현재 월을 기준으로 합니다. 모바일에서도 스크롤 중 테마 버튼을 사용할 수 있습니다.

## GitHub Pages 무료 배포 준비

배포는 아직 수행하지 않았습니다. 나중에 게시하려면:

1. `index.html`, `.nojekyll`, 이 안내를 GitHub 저장소의 `main` 브랜치 루트에 커밋하고 푸시합니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. 브랜치 `main`, 폴더 `/ (root)`를 선택하고 저장합니다. 이 단계부터 실제 배포가 시작됩니다.

GitHub Free에서는 공개 저장소의 Pages를 무료로 사용할 수 있습니다. 비공개 저장소는 계정 요금제의 Pages 지원 여부를 확인하세요. 별도 Actions 워크플로와 외부 호스팅 서비스는 필요 없습니다. 리소스를 상대 경로로 추가하면 저장소 하위 경로에서도 사용할 수 있습니다.

## 게시 전 확인

- 학원 연락처·주소·수업 정보와 사진을 실제 정보로 확인하세요.
- ‘시안 정보 수정’과 ‘사진 넣기’는 해당 브라우저의 로컬 저장소에만 저장됩니다. 다른 방문자에게 공유되거나 GitHub에 저장되지 않습니다. 공개할 정보·사진은 배포 파일에 반영해야 합니다.
- 이 페이지의 수정 버튼은 서버 관리자 인증 기능이 아닙니다.

Chromium 자동화 브라우저에서 320×640, 375×812, 390×844, 768×1024, 820×1180, 1024×768, 1440×900 화면을 검증했습니다. 작은 화면에는 터치 입력을 사용했습니다. 자동 및 사계절 테마 전환, 선택 유지, 상단 버튼 가림과 가로 넘침 여부, 정보 수정, 사진 등록 및 새로고침 후 사진 복원을 확인했습니다. 실제 iPad/iPhone의 Safari에서 수행한 테스트는 아닙니다.
